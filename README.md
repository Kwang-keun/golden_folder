## 🌱 프로젝트 소개

**VitaCore**는 건강 기능식품 정보 제공 및 판매를 위한 풀스택 정적 웹사이트입니다.  
복잡한 성분 정보를 시각적으로 쉽게 이해할 수 있도록 설계되었으며,  
사용자 건강 고민에 맞는 제품을 추천하는 인터랙티브 경험을 제공합니다.

### 핵심 가치
- **신뢰**: 식약처 인정 기능성 원료만 취급
- **명확성**: 복잡한 성분 정보를 쉽고 정확하게
- **개인화**: 건강 고민별 맞춤 추천

## 🚀 설치 및 실행

### 방법 1: 브라우저 직접 열기 (추천)
```bash
# 저장소 클론
git clone https://github.com/your-org/vitacore.git
cd vitacore

# index.html을 브라우저에서 열기
open index.html   # macOS
start index.html  # Windows
```

### 방법 2: 로컬 서버 실행
```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
npx serve .

# VS Code Live Server 확장 사용 가능
```

브라우저에서 `http://localhost:8080` 접속

## 💻 CLI 서브페이지 생성

```bash
# 비타민 도감 페이지 생성
node cli.js create vitamins

# 제품 목록 페이지 생성
node cli.js create products

# 제품 상세 페이지 생성
node cli.js create product-detail

# 건강 퀴즈 페이지 생성
node cli.js create quiz

# 장바구니 페이지 생성
node cli.js create cart

# 마이페이지 생성
node cli.js create mypage

# 모든 서브페이지 한 번에 생성
node cli.js create all
```

> CLI는 `cli.js` 파일이 생성된 후 사용 가능합니다. (별도 요청 시 생성)
