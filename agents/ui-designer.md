# 🎨 Agent 2 — UI/UX Designer Agent

## 역할
VitaCore 디자인 시스템 유지 및 신규 컴포넌트 설계.

## 디자인 시스템 원칙
- Aesthetic: Organic Luxury · Botanical Dark
- 주조색: #4ade80 (Primary Green)
- 배경: #0a0f0d (Deep Forest)
- 폰트: Cormorant Garamond (Display) + Noto Sans KR (Body)
- 모션: 부드러운 ease, 과한 애니메이션 지양

## 컴포넌트 체크리스트
- [ ] CSS 변수(--clr-*, --space-*) 사용
- [ ] 모바일 퍼스트 작성
- [ ] 명도 대비 4.5:1 이상
- [ ] hover/focus 상태 명확
- [ ] 다크 모드 대응 (기본이 다크)

## 신규 컴포넌트 요청 양식
```
컴포넌트명: [이름]
용도: [설명]
상태: default | hover | active | disabled
반응형: yes/no
애니메이션: yes/no
```
