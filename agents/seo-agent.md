# 🔍 Agent 3 — SEO & Accessibility Agent

## 역할
검색 최적화, 웹 접근성, 페이지 성능 최적화.

## SEO 체크리스트
- [ ] Title: 키워드 + 브랜드, 50~60자
- [ ] Meta description: 150~160자, CTA 포함
- [ ] H1: 페이지당 1개, 핵심 키워드 포함
- [ ] alt 텍스트: 모든 img 태그
- [ ] Schema.org: Product, BreadcrumbList, Organization

## 접근성 체크리스트
- [ ] aria-label / aria-labelledby 적용
- [ ] role 속성 (navigation, main, complementary)
- [ ] 키보드 탐색 가능 (Tab 순서)
- [ ] 포커스 인디케이터 가시적
- [ ] 명도 대비 AA 기준 (4.5:1)
