GoldenKP(이하 "운영자")가 제공하는 동네정보 · 로또645 · 꿈해몽 앱(이하 "앱")은 이용자의 개인정보를 소중히 여기며, 관련 법령(개인정보 보호법, 정보통신망법)을 준수합니다. 본 방침은 앱이 수집하는 정보의 종류, 이용 목적, 보관 기간 등을 안내합니다.

📌 본 방침은 위 3개 앱에 공통 적용됩니다. 앱마다 실제로 수집·이용하는 정보 항목은 서로 다르며, 각 항목은 아래 표에 앱별로 구분해 표기했습니다. GoldenKP 웹사이트의 회원가입·쇼핑몰 등 다른 서비스는 GoldenKP 개인정보처리방침을 따릅니다.
01

개인정보의 처리 목적

앱은 다음 목적을 위해 개인정보를 처리합니다. 처리한 개인정보는 다음 목적 외의 용도로는 사용되지 않습니다.

  • [동네정보] 현재 위치 기반 주변 장소(병원·약국·도서관·공공기관) 검색 서비스 제공
  • [동네정보] 카카오 장소 API 및 공공데이터포털 API 연동을 통한 정보 조회
  • [동네정보] 서비스 오류 분석 및 품질 개선
  • [로또645] 오행 테마 번호 생성 기능 이용 시, 입력한 생년월일을 기기 내에서만 활용해 결과 계산 (서버 전송 없음)
  • [꿈해몽] 검색어 및 즐겨찾기 기록을 기기 내에 저장해 재방문 시 편의 제공

03

개인정보의 보유·이용 기간

수집한 개인정보는 수집 목적이 달성되면 즉시 파기합니다.

  • [동네정보] 위치 정보: 검색 요청 처리 후 즉시 파기 (서버 저장 없음)
  • [동네정보] 검색 기록: 기기 내 최대 30일 보관 후 자동 삭제 (서버 미전송)
  • [공통] 자동 수집 정보: 서비스 오류 분석 후 90일 이내 파기
  • [로또645] 생년월일·저장함 항목: 사용자가 직접 삭제하거나 앱 삭제 시까지 기기 내 보관
  • [꿈해몽] 검색어·즐겨찾기: 사용자가 직접 삭제하거나 앱 삭제 시까지 기기 내 보관

단, 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

04

개인정보의 제3자 제공

운영자는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 3개 앱 중 동네정보만 서비스 제공을 위해 아래 API에 위치 정보를 전달하며, 로또645와 꿈해몽은 어떠한 정보도 외부로 전송하지 않습니다.

제공 대상제공 정보이용 목적
카카오 (Kakao Corp.) 검색 키워드, 위치 좌표 장소 검색 결과 제공
공공데이터포털 (data.go.kr) 위치 좌표 공공시설 정보 조회

각 서비스의 개인정보처리방침은 해당 서비스 웹사이트에서 확인하실 수 있습니다.

05

개인정보처리의 위탁

현재 운영자는 개인정보 처리 업무를 외부에 위탁하지 않습니다. 향후 위탁이 필요한 경우, 본 방침을 통해 사전 안내하겠습니다.

06

이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 개인정보 처리 현황 열람 요청
  • 개인정보 수정·삭제 요청
  • 개인정보 처리 정지 요청
  • 위치 정보 수집 거부 (기기 설정 → 앱 권한 → 위치 허용 해제)
위치 권한을 허용하지 않아도 앱의 키워드 검색 기능은 계속 사용할 수 있습니다. 다만, 현재 위치 기반 검색은 위치 권한이 필요합니다.
07

위치정보 이용

본 섹션은 동네정보 앱에만 해당합니다 (로또645·꿈해몽은 위치 정보를 이용하지 않음). 앱은 위치기반서비스사업법에 따라 아래와 같이 위치정보를 이용합니다.

  • 이용 목적: 현재 위치 주변 장소 검색
  • 수집 방법: Android 기기 GPS / 네트워크
  • 이용·보관: 검색 요청 처리에만 사용하며 서버에 저장하지 않음
  • 권한 명칭: ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION
  • 거부 방법: 기기 설정 → 앱 → 동네정보 → 권한 → 위치 허용 해제
